# service-front コンポーネントカタログ

AI チャットサービス **Service** のフロントエンド（`service-front`）で使われている UI コンポーネントのカタログです。デザインの整合性確認、a11y チェック、エッジケースの動作確認などに利用してください。

## 技術スタック

- **Next.js 16**（App Router / Server Components 前提）
- **React 19** + React Compiler
- **TypeScript**（strict + exactOptionalPropertyTypes）
- **Tailwind CSS v4**（`@tailwindcss/vite` プラグイン経由）
- **shadcn/ui** + Base UI（`@repo/ui` パッケージで配布）
- **Storybook 10**（`@storybook/nextjs-vite` フレームワーク）
- **Vitest** + Playwright（ユニット / browser テスト）
- **Biome**（lint / format）/ **markuplint**（マークアップ検査）

## アーキテクチャ

Feature-based 構成。詳細は `service-front/.claude/arch/feature-based.md` を参照。

```
src/
├── app/              ルーティング（route group: (authenticated) / (auth) / (public)）
├── features/         機能単位のドメインロジック・UI
└── shared/           複数 feature から使われる共通要素
    ├── components/   汎用 UI（layout/Header, Breadcrumbs, Footer など）
    ├── constants/    定数
    └── config/       設定（generatePageMetadata など）
```

ドメイン横断で使う UI primitive（Button, Dialog, Breadcrumb 等）は **monorepo の `@repo/ui` パッケージ**から import。shadcn の add コマンドで `packages/ui/src/components/` に生成されます。

## デザインシステム

shadcn/ui のトークン体系を採用。`packages/ui/src/styles/globals.css` の `:root` に `oklch()` ベースのセマンティックトークンが定義され、`@theme inline` で Tailwind utility（`bg-background`, `text-foreground`, `border-border` 等）に橋渡しされます。

- **light / dark**: `.dark` クラスを祖先に付けると切替（`@custom-variant dark`）
- **角丸スケール**: `--radius` を基準に `rounded-sm` 〜 `rounded-4xl` を生成
- **フォント**: アプリ本体は `Geist`（`next/font/google` 経由）

## コンポーネントの書き方

### Server Components がデフォルト

`'use client'` は必要なときだけ明示。データ取得は Server Components で行うのが原則。

### Story の配置

コンポーネントと **同一ディレクトリに co-locate**：

```
src/shared/components/layout/Header/
├── Header.tsx
├── Header.stories.tsx
└── index.ts
```

### Story の最小テンプレート

```tsx
import type { Meta, StoryObj } from '@storybook/nextjs-vite';
import { Header } from './Header';

const meta = {
    title: 'shared/layout/Header',
    component: Header,
    tags: ['autodocs'],
    parameters: { layout: 'fullscreen' },
} satisfies Meta<typeof Header>;

export default meta;
type Story = StoryObj<typeof meta>;

export const Default: Story = {};
```

`tags: ['autodocs']` で Docs タブが自動生成されます。
