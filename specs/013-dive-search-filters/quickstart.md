# Quickstart: ダイブログ検索・フィルタ強化

**Feature**: 013-dive-search-filters | **Date**: 2026-06-18

本機能が end-to-end で動くことを確認する検証ガイド。実装詳細は [plan.md](./plan.md) / [contracts/search-params.md](./contracts/search-params.md) を参照。

## 前提

- 認証済みユーザーでログイン済み（001-auth）
- `/dives` に複数のログがあり、検証用に **潜水日・最大水深・ダイブタイプが異なる**ログと、**最大水深が未記録**のログを各 1 件以上含む

## セットアップ

```bash
cd service-front
npm install
npm run dev     # http://localhost:3000
```

## 自動テスト

```bash
cd service-front
npm test            # Vitest: schema / list-query / search-params / コンポーネント
npm run test:a11y   # Playwright + axe-core（tests/a11y/dives-pages.spec.ts）
```

期待: 範囲バリデーション・深度 null 除外・URL 変換・詳細パネル展開時の a11y がすべてグリーン。

## 手動検証シナリオ（spec の受け入れ条件に対応）

| # | 操作 | 期待結果 | 対応 |
|---|---|---|---|
| 1 | 「詳細条件」を開き開始日・終了日を指定して検索 | 期間内（両端含む）のログだけ表示 | US1 / FR-001 |
| 2 | 開始日のみ指定 | 開始日以降が全件表示（上限なし） | US1 / FR-001 |
| 3 | 開始日 > 終了日で検索 | 検索実行されず入力エラー表示 | FR-006 |
| 4 | 深度の下限・上限を指定 | 最大水深がその範囲のログのみ表示。**水深未記録ログは出ない** | US2 / FR-002（Q1） |
| 5 | ダイブタイプを 1 つ選択 | その種別のログのみ表示 | US3 / FR-003 |
| 6 | ダイブタイプを「指定しない」に戻す | 種別の絞り込み解除 | US3 |
| 7 | 期間 + 深度 + タイプ + ポイント名を同時指定 | すべて満たすログのみ（AND） | FR-004 / FR-005 |
| 8 | 折りたたんだ状態を見る | 「詳細条件: N 件適用中」が見える | FR-012 |
| 9 | フィルタ適用後に「もっと見る」 | 絞り込み条件を保ったまま追加読み込み | FR-009 |
| 10 | フィルタ適用後の URL をコピー → 別タブで開く / 再読み込み | 同じ絞り込み結果が再現される | FR-010 / SC-004 |
| 11 | 一致 0 件になる条件で検索 | 「該当なし」+ フィルタ解除導線が表示され、押すと全件に戻る | FR-008 / SC-005 |
| 12 | 「クリア」を押す | すべてのフィルタが解除され URL もクリアされる | FR-011 |

## 確認ポイント

- URL に出るのは指定したパラメータのみ（空項目は付かない）。
- 深度・期間の片側のみ指定で「以上 / 以下」の開いた範囲になる。
- 深度フィルタの受付範囲は 0〜300m（最大水深のデータドメインに合わせる）。
- スキーマ変更・マイグレーションが発生していない（`supabase/migrations/` に追加がない）。
