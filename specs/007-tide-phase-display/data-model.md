# Data Model: 潮回り（導出値）

## メタ情報

| 項目 | 内容 |
|------|------|
| スキーマ変更 | **なし**（テーブル追加・カラム追加・マイグレーションすべて不要） |
| 永続化 | しない。潮回りは表示の都度算出する導出値（spec FR-004） |
| 算出実装 | `service-front/src/shared/lib/tide.ts` の純粋関数 |
| 関連機能 | [007 潮回り表示](spec.md) |
| ステータス | 確定 |

## 1. 参照する既存データ（変更なし）

| テーブル.カラム | 型 | 用途 |
|----------------|----|------|
| `dives.dive_date` | `date` | ダイビング記録の潮回り算出の入力（ドメイン型 `Dive.diveDate: string`） |
| `dive_plans.planned_on` | `date` | ダイビング予定の潮回り算出の入力（ドメイン型 `Plan.plannedOn: string`） |

いずれも既存カラムをそのまま読むだけで、制約・インデックス・RLS への影響はない。

## 2. 導出値: 潮回り（TidePhase）

| 項目 | 内容 |
|------|------|
| 型 | `TidePhase = 'spring' \| 'middle' \| 'neap' \| 'long' \| 'young'` |
| 表示ラベル | spring → 大潮 / middle → 中潮 / neap → 小潮 / long → 長潮 / young → 若潮（`TIDE_PHASE_LABELS`） |
| 入力 | `YYYY-MM-DD` 文字列。不正な形式・解釈不能な値は `null`（呼び出し側は潮回りを描画しない） |
| 月齢 | `((対象日の JST 正午 − 2000-01-06T18:14:00Z) / 86400秒) mod 29.530588853`（負値は周期を加算して 0〜29.53 に正規化） |
| 旧暦日相当 | `floor(月齢) + 1`（1〜30 の整数） |
| 決定性 | 現在時刻に依存せず、同一入力は常に同一出力 |

## 3. 旧暦日相当 → 潮名 対応表（全 30 日）

- 新月（月齢 0 付近 = 旧暦 1 日）と満月（月齢 14.8 付近 = 旧暦 15〜16 日）が大潮、上弦（月齢 7.4 付近 = 旧暦 8 日）と下弦（月齢 22.1 付近 = 旧暦 23 日）が小潮になる（SC-002）
- 「小潮 → 長潮 → 若潮 → 中潮」の並びが 1 周期に 2 回現れ、循環が閉じる（SC-003）
- `floor` ベースのため任意の入力日付が必ずいずれか 1 つの潮名に対応する（境界での未分類なし）

## 4. 検証用の基準日付（単体テストのフィクスチャ）

基準朔（2000-01-06 18:14 UTC）から導出される決定的な期待値。実際の天文現象との照合ではなく、本仕様の計算結果の回帰検知に使う。

| 日付 | 旧暦日相当 | 期待される潮名 | 備考 |
|------|-----------|---------------|------|
| 2000-01-07 | 1 | 大潮 | 基準朔の翌日（新月直後） |
| 2000-01-13 | 7 | 小潮 | 上弦付近 |
| 2000-01-16 | 10 | 長潮 | |
| 2000-01-17 | 11 | 若潮 | |
| 2000-01-18 | 12 | 中潮 | |
| 2000-01-21 | 15 | 大潮 | 満月（2000-01-21 は実際の満月日） |
| 2000-01-28 | 22 | 小潮 | 下弦（2000-01-28 は実際の下弦日）。対応表後半（旧暦 22〜24 日）の検証 |
| 1999-12-25 | 17 | 大潮 | 基準朔より前の日付。負の経過日数 → 周期加算で正規化するパスの検証 |

## 5. 精度と限界

- 平均朔望月の近似のため、真の朔望（新月・満月の瞬間）とは最大半日〜1 日程度ずれることがある。区分が公式の潮汐表と前後 1 日ずれる可能性は spec の Assumptions で許容済み（参考情報の位置づけ）
- 地点（海域）による補正は行わない。旧暦日ベースの潮名は地点非依存の慣習値である
