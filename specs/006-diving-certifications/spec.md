# Feature Specification: ダイビングライセンス保有資格管理

**Feature Branch**: `006-diving-certifications`

**Created**: 2026-06-12

**Status**: Draft

**Input**: User description: "ダイビングライセンスの持っている資格期間、資格取得日を実装"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 保有資格の登録と一覧表示 (Priority: P1)

ダイバーであるユーザーは、自分が保有しているダイビングライセンス資格（指導団体・資格ランク・取得日）をプロフィールに登録し、いつでも一覧で確認できる。複数の資格（例: オープンウォーター → アドバンスド → レスキュー）を段階的に取得していくのがダイビングの一般的なキャリアパスであるため、資格は複数件登録できる。

**Why this priority**: 資格情報の記録がこの機能の根幹であり、これ単体でも「自分の資格と取得日を記録・確認できる」という価値が成立する。後続の保有期間表示・編集削除はすべてこのデータの存在が前提。

**Independent Test**: ユーザーがプロフィールから資格を 1 件登録し、登録した指導団体・資格ランク・取得日が一覧に表示されることで単独テスト可能。

**Acceptance Scenarios**:

1. **Given** ログイン済みで資格が未登録の状態, **When** 指導団体・資格ランク・取得日を入力して登録する, **Then** 資格一覧に登録した内容が表示される
2. **Given** 資格を 1 件登録済みの状態, **When** 別のランクの資格を追加登録する, **Then** 一覧に 2 件の資格が取得日の新しい順に表示される
3. **Given** 資格登録フォームを開いた状態, **When** 取得日に未来の日付を入力して登録しようとする, **Then** エラーメッセージが表示され登録されない
4. **Given** 資格が 0 件の状態, **When** 資格一覧を表示する, **Then** 「資格が未登録である」ことと登録への導線が表示される

---

### User Story 2 - 保有期間の自動表示 (Priority: P2)

ユーザーは、登録した各資格について「取得日から現在までの保有期間（経過年月）」を自動計算された形で確認できる。ダイビングでは「ライセンス取得から何年・ブランクどのくらい」がショップやバディとの会話・申告で頻繁に使われるため、ユーザー自身が計算しなくても一目で分かるようにする。

**Why this priority**: ユーザーの依頼にある「資格期間」に応える部分。ただし取得日（User Story 1）が登録されていることが前提のため P2。

**Independent Test**: 取得日が登録済みの資格に対して、一覧・詳細表示で「保有期間: ○年○ヶ月」が正しく表示されることで単独テスト可能。

**Acceptance Scenarios**:

1. **Given** 取得日が 3 年 2 ヶ月前の資格が登録済み, **When** 資格一覧を表示する, **Then** その資格に保有期間「3年2ヶ月」が表示される
2. **Given** 取得日が当日の資格が登録済み, **When** 資格一覧を表示する, **Then** 保有期間が「0ヶ月」相当の表現で表示される（マイナスや空欄にならない）

---

### User Story 3 - 資格の編集・削除 (Priority: P3)

ユーザーは、登録済みの資格の内容（指導団体・資格ランク・取得日）を後から修正したり、誤って登録した資格を削除したりできる。

**Why this priority**: 入力ミスの訂正手段として必要だが、登録・閲覧（P1/P2)が成立していれば当面は再登録で代替可能なため P3。

**Independent Test**: 登録済み資格の取得日を変更して保存し、一覧に反映されること、および削除した資格が一覧から消えることで単独テスト可能。

**Acceptance Scenarios**:

1. **Given** 資格が 1 件登録済みの状態, **When** その資格の取得日を修正して保存する, **Then** 一覧に修正後の取得日と再計算された保有期間が表示される
2. **Given** 資格が 2 件登録済みの状態, **When** 1 件を削除する, **Then** 一覧には残り 1 件のみが表示される
3. **Given** 削除操作を開始した状態, **When** 確認を求められてキャンセルする, **Then** 資格は削除されない

---

### Edge Cases

- 取得日が未来の日付の場合 → 登録・更新ともにエラーとして拒否する
- 取得日がユーザーの生年月日より前の場合 → エラーとして拒否する
- 同一の指導団体・資格ランクの組み合わせを重複登録しようとした場合 → エラーとして拒否する（取り直し・更新は編集で対応）
- 保有期間の計算が月途中の日付をまたぐ場合（例: 1月31日取得で2月28日時点）→ 経過月数は切り捨てで統一する
- 資格を 1 件も登録していないユーザーのプロフィール表示 → 未登録状態の案内を表示し、他機能の利用は妨げない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ユーザーは自分のプロフィールにダイビングライセンス資格を複数件登録できる
- **FR-002**: 資格 1 件は「指導団体」「資格ランク」「取得日」の 3 項目を必須として構成される
- **FR-003**: 指導団体は主要団体（PADI / NAUI / SSI / BSAC / CMAS）から選択でき、該当しない場合は「その他」を選択できる
- **FR-004**: 取得日は過去または当日の日付のみ受け付け、未来日付およびユーザーの生年月日より前の日付は拒否する
- **FR-005**: システムは各資格について取得日から現在までの保有期間（経過年月）を自動計算して表示する。保有期間はユーザーが入力する項目ではない
- **FR-006**: 資格一覧は取得日の新しい順に表示する。取得日が同一の資格は登録日時の新しい順とする
- **FR-007**: ユーザーは登録済みの資格を編集・削除できる。削除時は確認を挟む
- **FR-008**: 同一ユーザー内で同一の指導団体・資格ランクの組み合わせは重複登録できない
- **FR-009**: 資格情報は本人のみが閲覧・登録・編集・削除でき、他のユーザーからはアクセスできない
- **FR-010**: 資格が未登録の場合、一覧には未登録であることと登録への導線を表示する

### Key Entities

- **保有資格（Certification）**: ユーザーが取得したダイビングライセンス 1 件を表す。指導団体・資格ランク・取得日を持ち、ユーザーに複数件紐づく。保有期間は取得日から導出される値であり、保存される属性ではない
- **ユーザー（既存）**: 資格の所有者。既存のプロフィール（生年月日を含む）と 1:N で資格に関連する

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーは資格 1 件の登録を 1 分以内に完了できる
- **SC-002**: 登録・編集・削除の結果が、操作完了後すぐに一覧表示へ反映される
- **SC-003**: 登録済みの全資格について、保有期間が取得日に基づいて正しく表示される（手入力ゼロ）
- **SC-004**: 不正な取得日（未来日付・生年月日以前）の登録試行は 100% 拒否され、ユーザーに理由が分かるメッセージが表示される
- **SC-005**: 本人以外のユーザーから資格情報へアクセスできたケースが 0 件である

## Assumptions

- 「資格期間」は、ユーザーの記述を「取得日から現在までの保有期間（経過年月）の表示」と解釈した。一般的なダイビングの C カードに有効期限はないため、「有効期限の管理」ではなく「保有歴の表示」を採用している
- 資格は 1 ユーザーにつき複数件登録できるものとする（段階的なランク取得が一般的なため）
- 登録項目は指導団体・資格ランク・取得日の 3 つに絞り、カード番号・講習店舗・インストラクター名などの付加情報は本機能のスコープ外とする
- 資格情報は設定配下の資格管理画面で表示・管理し、プロフィール設定から導線を設ける。他ユーザーへの公開・共有機能はスコープ外とする
- 取得日の「当日」判定はユーザーのローカル日付を基準とする
- 既存の認証機能（001-auth）とプロフィール情報（生年月日を含む）が利用できることを前提とする
