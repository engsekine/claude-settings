# Quickstart: ログのエクスポート（PDF / CSV）

本機能をエンドツーエンドで検証する手順。実装の詳細は `contracts/export-endpoint.md` と `data-model.md` を参照。

## 前提

- service-front の開発環境が起動できる（`pnpm dev` 等、リポジトリ標準手順）
- ローカル Supabase が起動し、テストユーザーでログイン済み（`test@example.com`）
- ダイブログが複数件、うち一部に写真添付があること（無ければ `/dives/new` と写真添付で作成）

## セットアップ

```sh
# 依存（PDF 生成ライブラリ）を追加後
pnpm install
pnpm dev
```

## 検証シナリオ

### S1. 全件 CSV バックアップ（US1 / FR-001, FR-004〜006, FR-009）

1. `/dives` を開き、エクスポートメニューから「CSV」を選ぶ
2. `dive-logs_<日付>.csv` がダウンロードされる
3. 表計算ソフトで開く → ヘッダー + 全ログ行、日本語が文字化けしない
4. メモにカンマ・改行を入れたログがある場合、列がずれない
5. ログ 0 件のユーザーで実行 → ヘッダー行のみの CSV（エラーにならない）

### S2. 紙ログ提出用 PDF（US2 / FR-002, FR-007, FR-007a, FR-008）

1. `/dives` でエクスポートメニューから「PDF」を選ぶ
2. `dive-logs_<日付>.pdf` がダウンロードされる
3. 各ダイブがログ欄として整形され、写真添付ログにはサムネイルが表示される
4. 写真なし／任意項目未入力のログでもレイアウトが崩れない
5. A4 で印刷 → 欄が用紙からはみ出さず判読できる

### S3. 単一ログのエクスポート（US2 / FR-010a）

1. ダイブ詳細 `/dives/[id]` を開く
2. 「この 1 本を PDF 出力」を実行 → 当該ダイブのみの PDF がダウンロードされる
3. ファイル名に潜水日・ポイントが含まれる

### S4. 一覧フィルタを引き継いだエクスポート（US3 / FR-010）

1. `/dives` で機能 013 の絞り込み（例: 期間 2025 年）を適用
2. その状態でエクスポート → 出力に 2025 年のログのみが含まれる
3. URL のフィルタクエリがエクスポート URL に引き継がれていることを確認

### S5. 複数選択エクスポート（US3 / FR-010b）

1. `/dives` で選択モードにし、3 件のログをチェック
2. 「選択分をエクスポート」→ 出力に選択した 3 件のみが含まれる
3. 0 件選択／絞り込み 0 件 → 「対象ログがない」案内が表示される（空ファイルを作らない）

### S6. 本人データ限定（FR-003 / SC-005）

1. 他ユーザーのログ ID を `?ids=` に混ぜて `/dives/export` を直接叩く
2. 出力に他人のログが一切含まれない（RLS により除外）

## 成否判定（Success Criteria 対応）

| シナリオ | 対応 SC |
|---|---|
| S1〜S5 を 2 ステップ以内で開始できる | SC-001 |
| 100 件規模で CSV / PDF とも 10 秒以内 | SC-002 |
| CSV が列ずれ・文字化けなく開ける | SC-003 |
| PDF が A4 で判読できる | SC-004 |
| 他人のログ混入 0 件 | SC-005 |

## 自動テストの入口

- 純粋関数: `pnpm test`（Vitest）で `export-csv` / `export-filename` / `export-params` / `build-pdf-data`
- UI: Storybook（`ExportMenu`・選択モードの `DiveList`）+ Playwright/axe-core（`/dives`・`/dives/[id]` の a11y）
