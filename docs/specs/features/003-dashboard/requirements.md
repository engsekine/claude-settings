# 003 ダッシュボード - 要件

## 概要

ログインしたダイバーの「今」を一目で把握できる TOP ページ（ダッシュボード）を提供する。本 feature には以下 3 つの要素を含む。

1. **TOP 画面**（`/`）の構成と認証
2. **累計統計機能**: 自分のダイブから累計本数・潜水時間などを集計
3. **レギュレーターオーバーホール（OH）機能**: 機材登録と OH 期限管理

関連スクリーン仕様: [`specs/screens/top.md`](../../screens/top.md)

## ユーザーストーリー

- ダイバーとして、自分の累計ダイブ本数と潜水時間を一目で確認したい
- ダイバーとして、TOP ページから新しいログ記録にすぐ移りたい
- ダイバーとして、レギュレーターの次回オーバーホール時期を忘れずに把握したい
- ダイバーとして、メイン機材以外のバックアップ機材も登録して管理したい
- ダイバーとして、オーバーホールを実施したら 1 タップで「完了」を記録したい

## 受け入れ条件

### TOP ページ（`/`）

- 未認証ユーザーが `/` を開いたとき、システムは `/login` にリダイレクトする
- 認証済みユーザーが `/` を開いたとき、システムはダッシュボードを表示する
- ダッシュボードは以下のセクションを含む:
  - ヒーロー（ユーザー名 + 前回ダイブからの経過日数 + 「新しいログを記録」CTA）
  - 統計カード（累計本数 / 累計潜水時間 / 最大水深 / 訪問スポット数）
  - レギュレーター OH 状況パネル
  - 最近のダイブログ（直近 5 件）

### 累計統計

- 認証済みユーザーが TOP を開いたとき、システムは自分のダイブから以下の集計値を表示する:
  - 累計ダイブ本数（行数）
  - 累計潜水時間（`bottom_time_min` の合計）
  - 最大水深（`max_depth_m` の最大値）
  - 訪問スポット数（`location` の distinct カウント）
- ダイブログが 0 件のとき、システムは各統計を `0` で表示し、最近のログ欄に「最初のログを記録しよう」CTA を表示する
- 累計潜水時間は「XX 時間 YY 分」形式で表示する（60 分未満なら「YY 分」）

### レギュレーターオーバーホール

#### 機材登録（`/settings/equipment`）

- 認証済みユーザーが `/settings/equipment` を開いたとき、システムは登録済みのレギュレーター一覧を表示する
- ユーザーは複数のレギュレーター（メイン / バックアップなど）を登録できる
- 必須項目（ブランド / モデル / 前回 OH 日）を入力して送信したとき、システムはレギュレーターを保存する
- 登録済みのレギュレーターは編集・削除できる
- 同一ユーザーで `is_primary = true` のレギュレーターは 1 件のみとする
- 最初に登録したレギュレーターは自動的に `is_primary = true` になる

#### OH ステータス表示（TOP 上）

- 認証済みユーザーが TOP を開いたとき、システムはメイン機材（`is_primary = true`）の OH ステータスを表示する
- レギュレーターが未登録のとき、システムは「レギュレーターを登録すると OH 期限をお知らせします」と表示し、登録画面へのリンクを提供する
- OH ステータスは以下のルールで判定する:
  - **余裕**: 残日数 > 30 日 かつ 残本数 > 10 本
  - **期限間近**: 残日数 ≤ 30 日 または 残本数 ≤ 10 本
  - **期限切れ**: 残日数 ≤ 0 または 残本数 ≤ 0
- 残日数 = `next_overhaul_date - 今日`
- 残本数 = `overhaul_interval_dives - (last_overhauled_on 以降のダイブ本数)`
- ステータスは色（青 / 黄 / 赤）+ アイコン + テキストで識別可能にする（色だけに依存しない）

#### OH 完了の記録

- TOP の OH カードに「メンテ完了を記録」ボタンを表示する
- ボタンをクリックすると確認ダイアログを表示し、OK を押すと `last_overhauled_on = 今日` に更新する
- 更新後、TOP の OH ステータスは新しい計算結果に切り替わる

## 必須項目

### `regulators` テーブル

- `brand`（ブランド名）
- `model`（モデル名）
- `last_overhauled_on`（前回 OH 日）

### TOP 画面の必須セクション

- ヒーロー
- 統計カード（4 種）
- 最近のダイブログ

レギュレーターパネルは「未登録のときは設定 CTA を表示」の形で必ず描画される。

## 対象外（Phase 1）

- 月別ダイブ本数グラフ（後続の feature で検討）
- レギュレーター以外の機材（BCD / ダイブコンピューターなど）の管理
- メイン機材切替 UI（最初の 1 件を自動で primary に。切替は edit 画面の `is_primary` チェックで対応）
- OH 完了の取り消し（操作ミス時は edit 画面で手動修正）
- カレンダー方式以外の OH リマインダー（メール通知など）

## 既存仕様への影響

- `src/proxy.ts` の `APP_ROUTE_PREFIXES` に `/` および `/settings/equipment` を追加する（または `/settings` プレフィックスに `equipment` 配下を含める）
- `src/app/page.tsx` を Welcome から本 feature のダッシュボードに置き換える
